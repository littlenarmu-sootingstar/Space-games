SPACE GAMES — iPhone 설치용 PWA

[아이폰에 설치하기]
1. 이 폴더의 모든 파일을 HTTPS를 지원하는 웹 호스팅에 업로드합니다.
2. 아이폰에서 Safari로 배포된 HTTPS 주소를 엽니다.
3. 공유 버튼을 누르고 '홈 화면에 추가'를 선택합니다.
4. 홈 화면의 SPACE GAMES 아이콘을 눌러 실행합니다.

[참고]
- App Store 앱이 아니라 홈 화면에 추가하는 웹 앱(PWA)입니다.
- 오프라인 캐시는 첫 온라인 접속 후 서비스 워커가 파일을 저장하면서 준비됩니다.
- 점수 기록은 해당 아이폰 브라우저의 로컬 저장소에 저장됩니다.
- Safari와 HTTPS 주소를 사용하세요.
